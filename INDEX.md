## 📋 Key Concepts Quick Reference

**Vertical Landing Page**
- What: Industry-specific solution page (e.g., "Hotels & Hospitality")
- Why: Targets high-intent keywords, speaking directly to each vertical
- Where: `/solutions/[vertical-name]/`
- How to: Read [CREATING_VERTICALS.md](CREATING_VERTICALS.md)

**Quote Form**
- What: 3-step form capturing project scope, budget, timeline
- Why: Qualifies leads before sales contact
- Where: Embedded on all solution pages and content pages
- How to: Read [IMPLEMENTATION_GUIDE.md](IMPLEMENTATION_GUIDE.md) section "Interactive Tools"

**Assessment Questionnaire**
- What: 6-question interactive tool that scores and recommends
- Why: Engages users, qualifies automatically, captures emails
- Where: Can be embedded on any page or standalone
- How to: Read [IMPLEMENTATION_GUIDE.md](IMPLEMENTATION_GUIDE.md) section "Interactive Tools"

**Case Studies**
- What: 4 detailed project stories with videos, metrics, testimonials
- Why: Builds trust, demonstrates ROI, shows past work
- Where: `/projects/case-studies/`
- How to: Read [IMPLEMENTATION_GUIDE.md](IMPLEMENTATION_GUIDE.md) section "Enhanced Case Studies"

**Buyer's Guides**
- What: 3 educational guides helping prospects make decisions
- Why: Positions PowerWave as expert, captures email for nurturing
- Where: `/resources/buyer-guides/`
- How to: Read [IMPLEMENTATION_GUIDE.md](IMPLEMENTATION_GUIDE.md) section "Buyer's Guides"

**Content Templates**
- What: Blog post, LinkedIn, video, and email templates with structure
- Why: Streamlines content creation, ensures consistency
- Where: `lib/content-templates.ts`
- How to: Read [IMPLEMENTATION_GUIDE.md](IMPLEMENTATION_GUIDE.md) section "Content Templates"
